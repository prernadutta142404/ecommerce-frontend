# NovaStore - Premium E-Commerce Website

NovaStore is a responsive front-end e-commerce website built using HTML, CSS and JavaScript.

## Features

✔ Responsive Design
✔ FakeStore API Integration
✔ Product Details
✔ Shopping Cart
✔ Quantity Update
✔ Checkout Page
✔ Order Confirmation
✔ Categories Page
✔ About & Contact Pages

## Technologies Used

- HTML5
- CSS3
- JavaScript
- FakeStore API
- Local Storage
